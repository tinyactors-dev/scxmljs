scxmljs playground

Demos for @tinyactors/scxmljs: an SCXML 1.0 interpreter (ECMAScript data model) and custom elements that render running statecharts in any framework.

Explorer

<scxml-explorer>

A running system at three levels — machines and services, one machine as a tree plus a focus, one state's details — with play, pause and step.

Neutral default

The same explorer without the Tinyactors stylesheet: what <scxml-explorer> looks like out of the box, following the page's light or dark scheme.

 Element

<scxml-view>

One chart as nested boxes with SVG arrows, clickable transitions, ::part() styling hooks and live source editing.
