Conformance

The interpreter is tested against the W3C SCXML 1.0 Implementation Report Plan test suite, converted to the ECMAScript data model. The converted suite is vendored in conformance/ (W3C licence in conformance/LICENSE-W3C), so running it needs no network. A test passes when its session reaches the top-level <final id="pass">. Time is virtual, so delayed events fire instantly and the whole suite runs in well under a second per data model.

Reproduce: mise run conformance (sandboxed), mise run conformance:trusted (trusted), mise run docs:conformance (this page). bun test runs the suite too, in both data models.

Summary#

Sandboxed (QuickJS) Trusted (host engine)
Mandatory tests 160/160 160/160
Optional tests 21/33 21/33

Every test that doesn't pass is optional and needs the Basic HTTP Event I/O Processor, which isn't included: 201, 509, 510, 518, 519, 520, 522, 531, 532, 534, 567, 577. See deviations.

Manual tests#

9 tests are marked manual: a person reads the output and decides. The verdicts, with the evidence for each, are in conformance/MANUAL.md: 8 pass, and 513 is not applicable (it needs the Basic HTTP processor). The mechanically checkable ones are also pinned in conformance/conformance.test.ts.

Deviations#

Where the interpreter deliberately differs from the specification, or leaves something out, is listed in deviations.md, each item pinned by a test.
