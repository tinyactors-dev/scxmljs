<scxml-view>

The whole chart at once, drop-in: <scxml-view src="…"> loads, validates, runs and draws a chart with no JavaScript of your own. Transition labels are buttons that send their event. Here GitHub is attached as an SCXML Event I/O Processor backed by a fake repo, through the element's options property. Open an issue as someone off the allowlist and watch the rejecting regions run in parallel.
