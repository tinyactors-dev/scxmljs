    Class PlaybackClock

    A VirtualClock that real time drives forward — at an adjustable speed — and that can be paused and stepped. For visualisations: everything that takes its time from this clock (sessions, delayed sends, fake services, simulated environments) slows down, stops and single-steps together.

    const clock = new PlaybackClock({ speed: 0.5 }); const session = await createSession(src, { clock }); clock.pause(); clock.step(); clock.play();
