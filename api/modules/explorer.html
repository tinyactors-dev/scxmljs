    Module explorer

    @tinyactors/scxmljs/explorer — the <scxml-explorer> custom element and the view-model behind it.

    Importing this module registers <scxml-explorer>. It works with sessions from either entry point (@tinyactors/scxmljs or …/trusted) and never pulls a data model in itself, so it adds no WebAssembly to your bundle.

    import { createSession, PlaybackClock } from "@tinyactors/scxmljs/trusted"; import "@tinyactors/scxmljs/explorer";

    const clock = new PlaybackClock(); const session = await createSession(source, { clock }); document.querySelector("scxml-explorer").attach({ session, clock }); session.start();
