# Measurements

Generated by `mise run bench` (`scripts/bench.ts`) on 2026-09-28. Raw data: `bench/results/`.

**Machine:** Apple M4 Max, 16 cores, 48 GB, darwin 25.6.0. **Runtimes:** Bun 1.4.1, Node v26.10.0.

Runtime numbers come from the built package (`dist/`), each measure in a fresh process. Medians unless noted.
